# Xbee-communication
Arduino and XBee communication experiments covering AT mode, API mode, and Arduino-to-Arduino communication.

1. Using only XBee
Basic serial communication using XBee modules configured in AT mode and API mode.

2. Arduino (connected with XBee) and XBee (AT Mode)
-Direct message
-Using serial monitor

3. Arduino-to-Arduino (both connected to XBee (AT mode)

4. Arduino (connected with XBee) and XBee (API Mode)

# Software
- Arduino IDE
- XCTU

# Hardware
- Aruduino UNO Boards (×2)
- XBee Modules (×2)
- USB Cables (×2)
- Jumper Wires
